# Референсы для редизайна designcodes.ru

Стиль: минимализм. Клиенту показываем три направления. Доска: `moodboard/index.html`.

## C. Воздушный минимализм

Почти белый фон, светлые градиенты, много пустого места, мягкий акцент. Harno и Omnix Studio перенесены сюда из A.

- [Renewable Energy](https://dribbble.com/shots/26904119-Renewable-Energy-Landing-Page-Minimal-UI-Maximum-Impact)
- [AI Technology Landing](https://dribbble.com/shots/27748847-AI-Technology-Landing-Page-Artificial-Intelligence-Solutions)
- [AI Accuracy](https://dribbble.com/shots/27133849-AI-Accuracy-Landing-Page)
- [AI Enterprise](https://dribbble.com/shots/27424439-AI-Enterprise-Website)

## A. Продуктовый минимализм

Светлая база, карточки и бенто-сетки, вместо фото — скриншоты сайтов из портфолио, один яркий акцент, местами тёмные блоки-вставки.

- Clause и Harno — первые референсы Ивана, основа направления
- [Agency Pricing Section](https://dribbble.com/shots/27716691-Agency-Pricing-Section-Web-Design-Service-Packages) — карточки услуг веб-студии (визитка, лендинг, магазин) с ценой и сроком, почти готовый блок
- [Omnix Studio](https://dribbble.com/shots/27577180-Omnix-Studio-Photography-Studio-Website-Design) — светлый воздушный первый экран, строка логотипов клиентов
- [NORTHSTAR](https://dribbble.com/shots/27893183-NORTHSTAR-Studio-Management-SaaS-Website-Design) — первый экран с интерфейсом продукта, подойдёт для Битрикс24
- [FinTech Analytics Hub — Bento Grid](https://dribbble.com/shots/27546924--FinTech-Analytics-Hub-Bento-Grid-UI-Layout) — бенто-сетка возможностей вместо нынешнего слайдера Битрикс24
- [Looper](https://dribbble.com/shots/24127094-Looper-Website-design-for-the-aviation-procurement-platform) — сетка скруглённых карточек, крупные цифры
- [Keven](https://dribbble.com/shots/27663792-Keven) — блок «Selected Works» с крупными превью кейсов

## B. Типографический минимализм

Почти без картинок: крупный гротеск, строгая (швейцарская) сетка, моноширинные подписи, кейсы — крупные превью.

- [Portfolio Website Design 2026](https://dribbble.com/shots/27149012-Portfolio-Website-Design-2026) — сайт веб-студии: услуги таблицей, нумерация, крупный заголовок
- [DesignToWeb](https://dribbble.com/shots/14733234-DesignToWeb-Website) — студия «вы проектируете, мы программируем», та же идея design + code; один яркий акцент
- [Swiss Minimal Portfolio for Studios](https://dribbble.com/shots/27816607-Swiss-Minimal-Portfolio-Website-for-Studios) — огромное название + лента работ
- [Benjamin Righetti](https://dribbble.com/shots/15965702-Benjamin-Righetti-Website) — предельно чистый первый экран, только шрифт
- [JH — Editorial Portfolio](https://dribbble.com/shots/27288946-JH-Editorial-Art-Director-Portfolio-Personal-Website-UI-Design) — редакционная сетка, контраст размеров текста
- [Swiss Website Design 2025](https://dribbble.com/shots/26737472-Swiss-Website-Design-2025) — манифест крупным текстом, нумерация `//2213` — близко к «коду»
- [MOORR](https://dribbble.com/shots/27739932-MOORR-Clean-Portfolio-Readymag-Template) — чистая сетка портфолио
