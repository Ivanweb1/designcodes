// 05 · Возможности, ограничения и стоимость

Что важно учесть
до старта интеграции

01 / Дополнительно

Форматы сообщений и расширение

  • Интерактив и вложения: поддерживаем кнопки, медиа, файлы, отправку в рабочие группы и каналы.
  • Сложные форматы: Rich Messages Telegram и мини-приложения (Mini Apps) реализуем только после отдельной технической оценки.
02 / Ограничения платформ

Правила Telegram, MAX и ПД

  • Telegram: бот не может написать пользователю первым — пользователь должен сам запустить диалог с ботом.
  • MAX: для запуска и работы требуются верификация и прохождение модерации на стороне платформы.
  • Законодательство: все сценарии рассылок и сбора заявок проектируются с учётом правил платформ и требований к персональным данным.

Стоимость — по задаче

Зависит от платформ (Telegram, MAX или обе), числа сценариев и необходимости двустороннего обмена с Битрикс24. Ориентир по почасовым ставкам можно посмотреть в прайсе специалистов.

// 06 · Частые вопросы

Коротко о главном

Откуда бот может получать данные?+

С сайта на 1С-Битрикс и из Битрикс24 через доступные механизмы интеграции — API и вебхуки.

Можно ли отправлять уведомления клиентам?+

Да, по разрешённому сценарию с учётом правил Telegram и MAX, а также требований к обработке персональных данных.

Может ли бот передать заявку в CRM?+

Да, при поддержке API и заранее согласованной логике передачи и обработки данных.
